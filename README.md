## Description
This project is a Restaurant Management System developed using Python.  
The system runs in the terminal and allows users to manage restaurant orders and menu items.

## Features
- View restaurant menu
- Add meals and beverages to customer orders
- Calculate total bill
- Display current order
- Interactive terminal-based system

## How to Run
1. Download the project files from the Google Drive folder above.
2. Open the project folder in Visual Studio Code.
3. Run the Python file using:

```bash
python main.py
